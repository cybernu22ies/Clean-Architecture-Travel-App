# CA Travel App

Простое приложение, запрашивающее данные с сервера и отображающее информацию об авиабилетах и доступных турах в виде нескольких взаимосвязанных экранов. Проектирование приложения происходило по принципам Clean Architecture и архитектурного паттерна MVVM.

![app screenshots](https://github.com/RUD0MIR/Clean-Architecture-Travel-App/blob/main/app_screenshots.png?raw=true)


#### При создании приложения использовались следующие технлогии:

- Kotlin
- Kotlin Coroutines
- Kotlin Flows
- Dagger - Hilt
- Jetpack Navigation Component
- Data Store
- Retrofit
- XML layouts
